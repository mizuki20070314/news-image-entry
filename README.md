# The World — November 23, 2026

One image that sums up the world's news of Monday, November 23, 2026, built for make.fun's
"Sum up 23 November's world news in one image" bounty.

A hand-laid newspaper front page: the collapse of COP31 in Antalya, the Delta outage that
grounded Atlanta, the Gibraltar-tight Hormuz standoff, Vietnam's floods, the Benghazi warship
strike, and the day's other stories across every continent.
